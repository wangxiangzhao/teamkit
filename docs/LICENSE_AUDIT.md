# License and third-party skill audit

This repository is publicly accessible, but **a project-level distribution license has not been selected by the repository owner**. TeamKit must not advertise itself as MIT-licensed without the owner's authorization. Package metadata therefore intentionally omits a project license identifier. Usage in the owner's projects does not imply redistribution rights for other parties.

**Bundled third-party material:** `src/teamkit/assets/skills/swiftui-pro` is copied from [Paul Hudson's SwiftUI Agent Skill](https://github.com/twostraws/SwiftUI-Agent-Skill) at commit `f2920b63995263f57b3e198674e89a602efba6d2`. It is independently MIT-licensed, carries its original `LICENSE`, and includes all Markdown references required by its `SKILL.md`.

All other external sources in `sources.json` are **discovery candidates**, not automatically installed or redistributed.

Before any external package publication, the repository owner must explicitly set the TeamKit project's intended distribution terms and review dependencies and attribution. No licensing change is required merely to run TeamKit internally.

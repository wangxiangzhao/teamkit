# TeamKit V1 verification boundaries

The portable build verifies CLI syntax, deterministic routing, local project scanning, DAG transitions, evidence lifecycle, explicit build/test command consent, image size and byte duplicates, and numeric ROAS calculations.

## Requires external verification

- On a Mac: current Codex CLI role config compatibility, authentication and native multi-agent execution.
- On Xcode: simulator, builds, XCTest, UI transitions and screenshot quality.
- With Figma authorization: actual design node extraction and visual comparison.
- With revenue/analytics permission: source data, attribution, tracking, refunds and profit.
- With real matched tasks: token, wall-clock and quality efficiency gains.

This version never claims test evidence that has not been observed. Any environment prerequisite not satisfied is **blocked** or **not-run**, never passed. External Skills remain candidates until independently reviewed.

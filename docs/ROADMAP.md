# TeamKit delivery plan

## M0 — 0.1.0 foundation (implemented)
- Portable Python package and CLI; 8 role definitions.
- Safe role installation, environment discovery, project scanning, SHA-256 sync.
- Advisory task routing, sequential plan and persisted checkpoints.
- Inventory quality evidence and regression tests.

## M1 — native Codex integration
- Validate current Codex role format/config against official documentation and CLI versions.
- Read-only project context selector, AST-aware indexing and module impact graph.
- Skills registry with source, license, revision, tested capability and activation rules.
- Native child-agent dispatch integration with bounded concurrency and report contracts.
- Config backups, rollback, permission and error paths.

## M2 — macOS / iOS
- Xcode scheme discovery, xcodebuild and XCTest evidence, simulator resource locks.
- Image validation pipeline, Figma design contract and UI screenshot comparison.
- High-risk invariants and change-based QA gates.

## M3 — business/data
- Read-only connectors, privacy-aware event dictionary, SQL/ROAS calculations.
- Real benchmark suites for token cost, wall clock, reliability and quality.

Never claim a phase complete without reproducible verification.

# Analytics and ROAS
1. Start with verified sources, permissions, attribution window, currency, time zones and cohort definition.
2. Separate acquisition date cohorts from calendar revenue; distinguish gross proceeds, platform deductions, ad revenue, refunds, fees and net profit.
3. Calculate ROAS = attributed revenue / acquisition spend using SQL/Python. Report D0, D1, D7, D14, D30 only when observation windows are complete.
4. Model payback, forecasts and LTV with assumptions, confidence ranges and sensitivity analysis; never describe them as observations.
5. Reconcile advertising and analytics SDK IDs and timestamp offsets; avoid double-counting event or revenue callbacks.
6. Present cohort curves, channel comparisons, spend, retention, revenue and contribution margin in actionable visual reports.
7. Keep production campaign budgets and monetization controls read-only unless separately approved.

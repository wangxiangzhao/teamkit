# TeamKit

Local-first, low-token Codex project adapter and deterministic orchestration toolkit.

## Status

**v0.1.0 foundation under development.** The first milestone implements safe agent installation, project scanning, incremental sync, advisory task routing, checkpoints, and honest validation. It does not claim live Codex child-agent dispatch, macOS/Xcode integration, or Figma screenshot verification.

## Goals

- One Codex Master + eight professional agent profiles.
- Shared skills, scoped project extensions, minimal relevant context.
- Local deterministic inspection, task routing and state persistence.
- Risk-driven quality checks and explicit evidence.
- No unauthorized changes to Codex credentials or existing configuration.

See the source files, tests, and the roadmap for implemented versus planned capabilities.
